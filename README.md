This is a proof of concept for a platformer game played in your terminal.

## Installation

In cloned repo run:

```shell
cargo run
```

## Controls

- `a`/`d` to dash left / right
- `w` to dash up
- `s` to charge jump -- pressing `a`/`d` next will perform a jump in the respective direction
- `q` to quit
